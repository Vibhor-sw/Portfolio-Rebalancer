# Portfolio Rebalancer

Mobile-first equity portfolio optimization and rebalancing tool for retail investors, built with React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui.

Implements the full Portfolio Rebalancer PRD: Dashboard, Holdings, Optimizer, Rebalancer, Execute Orders, Execution Mode/Flow, Settings, How It Works, FAQs, and the **WhatIf Simulator** — a conversational what-if engine that computes real allocation, sector, risk-profile, and cash-injection scenarios against your live holdings and can push the results straight into the Rebalancer flow.

All data is mocked/in-memory (no backend), per the PRD's scope.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
